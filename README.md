\# UI



A minimal, accessible and customizable React component library.



UI is a React component library built with TypeScript, Tailwind CSS and CSS variables. It provides reusable components with a focus on simplicity, consistency and accessibility.



\## Features



\- Built with React and TypeScript

\- Tailwind CSS integration

\- Customizable design tokens

\- Accessible components

\- Lightweight and reusable

\- Next.js compatible



\## Components



\- Button

\- Input

\- Field

\- FieldGroup

\- FieldGrid

\- FieldLabel

\- FieldDescription

\- FieldError

\- InputGroup

\- InputGroupAddon

\- ButtonGroup



\## Tech Stack



\- React

\- TypeScript

\- Tailwind CSS

\- tsdown

\- pnpm workspaces



\## Project Structure

ui/

\## Development



Install dependencies:



```bash

pnpm install

```



Build the React package:



```bash

pnpm --filter @ui/react build

```



Run the documentation site:



```bash

pnpm --filter docs dev

```
